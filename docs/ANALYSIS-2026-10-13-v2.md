## 3. Соответствие видению «Gaming Optimization Center» (скриншот IQON)

Что на скриншоте → что есть → что реально сделать **без фиктивных метрик**:

| Блок на макете | Сейчас в Visor | Реализуемо честно | Ограничение |
|---|---|---|---|
| Processor: модель, загрузка, °C | модель + загрузка (WMI/PDH) | загрузка — да (PDH/`NtQuerySystemInformation`, без handle'ов) | **Температура CPU** без драйвера ядра недоступна. Варианты: показывать «n/a», либо опциональный модуль через LibreHardwareMonitor — требует админ-прав и драйвера, часть античитов/антивирусов к этому чувствительна |
| Video Card: модель, загрузка, °C | модель | **да**: NvAPI отдаёт загрузку, температуру, тактовые частоты, причины троттлинга; AMD через ADL — частично | — |
| RAM: объём, тип, загрузка | объём | да (`GlobalMemoryStatusEx`, WMI для DDR-типа/частоты) | — |
| Storage: модель, заполненность, здоровье | свободное место | да: модель/тип (SSD/HDD/NVMe), SMART-здоровье через `MSFT_PhysicalDisk` без админа | Температура NVMe — обычно только с админом |
| Network: имя, скорость ↑↓, график | адаптер, ICMP, DNS | да: счётчики байт/с адаптера, Wi-Fi уровень сигнала и канал через WlanAPI (без админа), traceroute, link speed | «Причина высокого пинга» — только эвристики по данным (джиттер на 1-м хопе = Wi-Fi/роутер, потери за шлюзом = провайдер) |
| Performance Analyzer (FPS) | нет | **только через ETW/PresentMon** (Intel, MIT): FPS, frame time, 1 % low, оценка click-to-photon | **Требует прав администратора** для ETW-сессии. Без оверлея в игру (инъекции не будет) — показ в OSD-окне Visor поверх игры |
| Optimization «в 1 клик» | SafeAction (Game Mode, план) | да, но только список обоснованных и обратимых действий: Game Mode, Xbox Game Bar в фоне, оптимизация полноэкранного режима **для конкретного exe**, ускорение мыши, план питания per-game (уже есть), HAGS (нужен админ) | **Не делать**: «очистку» реестра, отключение сервисов, TCP-твики, Debloat системных компонентов. «Прирост FPS» не обещать — измерять до/после PresentMon'ом |
| Health Center / Drivers | конфликты, крашы | да: версия драйвера GPU и дата, статус Game Mode, ночной свет, план питания, SMART, события WHEA/kernel-power из журнала (крашы/перегрев) | Проверка «нужно обновить драйвер» — только сравнение даты, без скачивания |
| Dashboard / Home | карточки сессии, библиотеки | да: карточки CPU/GPU/RAM/диск/сеть + приоритетные рекомендации из реальной диагностики | обновление только когда окно видно |
| Themes, Tooltip Mode | темы есть | да, Tooltip Mode — дёшево (InfoHint уже есть) | — |
| 24/7 Support, аккаунт | нет | **не делать** — нет бэкенда; вместо этого «Export diagnostics» в zip | — |
| Input latency | нет | только оценка из PresentMon (Click-to-Photon) при включённом мониторинге | аппаратно не измерить |

### Этап 1 — оболочка под макет
Навигация: **Home · My PC · Games · Optimize · Network · Monitor · Settings** (Presets → вкладка внутри Games; Tools → History/Log в Settings). Страницы — отдельные `UserControl`. Карточки, кольцевые индикаторы, статусные точки — на текущих theme-brush'ах, с reduced-motion.

### Этап 2 — My PC + Home
`HardwareInfoService` (инвентарь, кэш на сессию) + `SensorService` (1 Гц, только пока страница видна): загрузка CPU/GPU/RAM, GPU °C/частоты/троттлинг (NvAPI, ADL), SMART, сеть ↑↓. Home собирает карточки + «здоровье» (драйвер, крашы из журнала, план, Game Mode).

### Этап 3 — Optimize с откатом
Переписать SafeAction: персистентный журнал действий с точным «как было» (включая «значения не было»), проверка текущего состояния перед откатом, блокировка на время игровой сессии, список действий из §3. Рекомендации только из измеренных фактов, с текстом «что даёт / риск / как откатить».

### Этап 4 — Network

### Этап 5 — Monitor (FPS)
