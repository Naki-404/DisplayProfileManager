# UX pass — 2026-10-17

Scope: menus, scrollbars, popups, shell alignment, forms, dialogs/overlays (owner report: "menus look uneven,
scrollbars visible where they shouldn't be, external UX components look wrong"). Verified by build (0 errors /
0 warnings), a static StaticResource-resolution check over App.xaml + every View, and new STA unit tests that load
`<Application.Resources>` as a plain ResourceDictionary and instantiate the menu / dropdown / scroll / button
templates (`tests/Visor.Tests/ThemePaletteTests.cs` → `AppResourceDictionaryTests`). The app itself was not run.

## Not changed / out of my file scope (follow-ups)

- ✅ *Fixed in the integration pass (item sizes scaled by `menu.DeviceDpi / 96`, preset rows use 12-DIP padding).* **Tray menu sizes (App.xaml.cs `RebuildTrayMenu`)**: items used `AutoSize=false`, `Height=32`, `Width=200/220/240`, separators `Height=7` in raw pixels, so at 150 % the rows are 32 *physical* px (≈21 DIP) and labels like "Toggle overlay: Ctrl+Alt+O" can ellipsize. Should be `LogicalToDeviceUnits(...)` / scaled by `menu.DeviceDpi / 96`. Preset rows are indented with two spaces (`"  " + p.Name`); a renderer-side indent would be cleaner. The renderer side (colors, insets) is fixed in UiHelpers.cs.
- Main-window toast (`MainWindow.xaml` ToastHost) still has a DropShadowEffect on the text container; left as is because code sets `ToastHost.Padding` and animates it as a Border.
- StatusDot vertical centering: dots are layout-centered on the text line box, which reads ~1 DIP high against Segoe UI's x-height; left unchanged (would shift every dot, several have hand-tuned margins).

## Manual visual check for the owner (≈10 min)

1. **Games → ⋯ (under the list and in the editor header)**: menu opens right-aligned under the button, dark themed, no white strip on the left, rows equal height, separator inset, disabled Duplicate/Export when no game is selected. Repeat in Light theme and at 150 % scaling.
2. **Tray icon → right-click**: hover highlight is a rounded inset pill with a thin border, text doesn't turn cyan, submenu chevrons aligned, at 125/150 %.
3. **Any dropdown** (rail Theme, Games → Display → Refresh rate, Settings → Zoom factor): list flush with the field's left edge, rounded rows, highlight visible on the selected row while moving with arrow keys; editable (Resolution) vs read-only combo same height.
4. **Optimize / Network / My PC pages**: no scrollbar at rest; moving the mouse or wheel shows a thin bar in the right gutter (not over the cards), widening when hovered; it fades ~1 s after you stop. Home at 1366×768 @125 % should show no bar at all.
5. **Games editor tabs / Settings → Defaults, Hotkeys, Monitor**: inner bar stays inside the card's rounded corners.
6. **Nav rail**: hover an item (wash fills the pill), hover the *selected* item (no darkening), collapse the rail (only the » button at top, centered; icons centered; accent bar on the left edge of the selected pill).
7. **Buttons in a row**: Games header (Apply now / Launch / ⋯), Network Start/Stop, dialog footers — identical heights.
8. **Home at a narrow window** (drag to minimum width): welcome card and stat grid bottoms aligned; stacked cards have 12-DIP gaps and straight edges.
9. **Command palette (Ctrl+K)**: rounded corners without a square frame.
10. **Overlay (Live color panel + mini pill) and FPS OSD** during a game: crisp text, centered chevrons, "FPS" on the number's baseline.
